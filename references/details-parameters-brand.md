# 细节、参数、品牌介绍与获奖标识

## 细节展示（可选）

来源：S43 规范板；S44 宫格模板；S45 横版模板。

### 共同结构

白色模块底 `#FFFFFF`；顶距140px；模块标题72px Semibold、`#000000`，只一行。标题至图片区80px；标题文字左右80px安全区；图片左右50px安全区，形成980px有效图区。图片区之后底距50px。图片均为直角。

### 宫格：图文错位交替

| 项目 | 规范 |
|---|---|
| 图片 | 限宽460px，高自定义 |
| 文字块 | 固定底色`#F1F2F1`；示例与图片同高 |
| 文字块宽度 | 示例980px总宽减460px图片区，得520px（结构推导） |
| 子标题 | 52px Medium、`#000000`，最多2行，行距66px |
| 描述 | 42px Regular、`#585858`，最多2行，行距56px |
| 子标题 → 描述 | 30px |
| 上下图文组之间 | 30px |

第一组为文字左、图片右；第二组为图片左、文字右；示例文字在块内居中。不要擅自改成两列各490px，那会改变明确460px的图片区。两幅图的400px高只是S44示例，原图允许自定义高度。

图素与底色必须明显区分，不涂抹图素做画面过渡。源文末词写“画面过度”，已核对为原图疑似笔误，见 [evidence-notes.md](evidence-notes.md)。

### 横版：文字叠在整张图片上

图片宽980px，高自定义；图与图之间30px，底距50px。每幅图片的色调不限，但文字所在区域简洁、清楚。第一幅文字左对齐，第二幅两行文字右对齐，形成左右交替。

图内文字从对应侧图片边缘内缩70px，不把这个70px当成两图之间间距。主标题与描述之间30px。横版区没有重新列一套字阶，可继承同板细节子标题52/66 Medium和描述42/56 Regular；这属于同板模板对应，不能宣称横版独立重新标了字号。S45的400px高也是示例。

## 规格参数（必备，有且只有1P）

来源：S08 规范板；S33 尺寸图+参数；S42 纯参数；S13 多SKU+参数。

原图允许“文本”“表格”两种排版按需选择，但详细示例均为文本样式。本 skill 对表格不补造网格、行高或表头规范。参数页只设置一个模块，多SKU不拆成多个参数标题页。

### 文字、线条和间距

| 项目 | 数值 |
|---|---|
| 模块底 | 固定`#FFFFFF` |
| 标题 | 72px Semibold，`#000000`，只一行 |
| 参数名与值 | 42px Regular，`#000000`，行距76px |
| 名/值列之间 | 100px |
| 分隔横线 | 高2px、宽920px、`#D7D7D7` |
| 顶距 / 底距 | 各140px |
| 左右文字安全区 | 各80px |
| 标题 → 首条横线 | 40px |
| 首条横线 → 尺寸图或纯参数 | 70px |
| 尺寸图 → 参数 | 70px |
| 多SKU组 → 横线 → 下一组 | 横线上下各70px |

### 结构选择

- **纯参数**：一行标题 → 横线 → 参数名/值列表。没有尺寸图时将文字向上顺移，不保留空白尺寸图区。
- **尺寸图+参数**：一行标题 → 横线 → 产品线性尺寸图 → 参数列表。尺寸标线简洁，不能为彩色。尺寸数值来自实际商品资料。
- **多SKU+参数**：共用一个标题；SKU组之间用同款横线分隔；整体仍只有1P。

S42的728px、S33的1397px、S13的1137px都是对应案例高度；“只有1P”不表示固定这些高度，也不表示整个产品长页只能一页。示例四行参数项不限制真实参数数量。

原图示例的电压行有尺寸数值混入，不能直接复制为产品事实。关于“表格”但无细则等缺项见 [evidence-notes.md](evidence-notes.md)。

## 品牌介绍（必备，固定放参数页下方）

来源：S11 规范板；S09 单图模板；S10 双图模板。单图与双图按需选一种，其余文字与间距相同。

### 结构与文字

整模块固定底色`#F1F2F1`，左右80px文字安全区。内容顺序：品牌logo → 公司名称全称 → 品牌slogan → 相关配图 → “品牌介绍”小标题 → 品牌正文。

| 元素 | 规范 |
|---|---|
| logo区 | 限高90px，宽不限；仍位于有效版心内 |
| 公司名称全称 | 72px Semibold，`#000000`，一行内 |
| 品牌slogan | 42px Medium，`#000000`，一行内 |
| “品牌介绍”小标题 | 42px Medium，`#000000` |
| 品牌正文 | 36px Regular，`#000000`，行距62px，控制在5行、110字符内 |
| 一张配图 | 920×400px |
| 两张配图 | 每张440×400px，中间40px |

图片与公司品牌相关，可展示主打产品组合、主打单品或本次发售产品的场景。正文可说明品牌历史、定位、愿景、公司位置等。不要把案例公司、绿色图片占位块或写着“LOGO”的色块当成真实品牌内容。

### 垂直节奏

| 关系 | 间距 |
|---|---:|
| 模块顶部 → logo | 90px |
| logo → 公司名称 | 50px |
| 公司名称 → slogan | 50px |
| slogan → 配图 | 80px |
| 配图 → “品牌介绍” | 100px |
| “品牌介绍” → 正文 | 50px |
| 正文段之间 | 50px |
| 模块底部 | 140px |

“logo宽不限”不表示可以越过模块安全区。原图未规定110字符的具体计数口径，可保守按全部可见字符计，但说明这是实施方式。S09/S10的1510px高是案例，不是固定模块高度。单图400px高的重复标注不表示两张纵向图片。

## 获奖标识（特殊正文模块，按需）

来源：S47 规范板；S46 正确实例。只出现在正文，不将获奖模块搬到头图。

| 项目 | 规范 |
|---|---|
| 画布 | 1080px宽，高不限，建议不超过手机1屏 |
| 背景 | 标注`#F1F2F1` |
| 左右文字安全区 | 各80px |
| 奖项logo/图形安全区 | 限高90px，宽不限；不拉伸资产 |
| 奖项标题 | 42px Medium，行距62px，默认黑/白按背景可读性选择 |
| 描述 | 36px Regular，行距50px，`#585858` |
| 顶部 / 底部 | 各100px |
| logo → 奖项标题 | 50px |
| 奖项标题 → 描述 | 30px |

文字颜色原图允许根据实际情况更改。采用对应产品真实获奖信息与正式奖项资产；图中iF、GOOD DESIGN、reddot及年份仅为案例。S46的604px不是强制模块高度；“手机1屏”没有换算成固定px上限。
