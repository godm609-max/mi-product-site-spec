# 基础设计系统

来源：S36《文字规范说明.jpg》，画布与安全区由各模块标注图确认。所有 px 是 1080px 宽设计稿中的像素值。

## 画布、尺度与证据

- 产品站页面宽 1080px，高度不限。头图建议不超过一手机屏；不是要求所有模块均等高。
- 5760×3240、5760×1360 是规范演示板尺寸，1280×624 是 FAQ 规范截图尺寸；均不是产出画布尺寸。
- 红色箭头、尺寸文字、红/黄/紫半透明安全区是说明层，制作成品时移除。
- 1080px 单独模板中的内容高度是示例尺寸，除图上明确写“固定/不可更改”之外，不自动上升为所有产品的硬性高度。
- 模块明确标注 > 通用字阶表示例 > 未标注的成品外观。用局部标注解释某模块，不把局部例外推广到全站。
- 设计稿转为其他显示宽度时，可用 `显示宽度/1080` 等比换算；这是实施建议，不是原图中的响应式断点规范。

## 字体

使用 MiSans，原图列明 Regular / Medium / Semibold 三档。用字号、字重与间距区分层级，保持页面一致。原图称 MiSans“永久可商用”；本 skill 不捆绑字体文件。

使用实际安装的 `MiSans-Regular.otf`、`MiSans-Medium.otf`、`MiSans-Semibold.otf`。Windows 可检查 `%LOCALAPPDATA%/Microsoft/Windows/Fonts/` 和 `C:/Windows/Fonts/`；其他系统按实际字体安装位置查找，不依赖特定用户路径。

## 通用字阶（S36）

| 用途 | 字重 | 字号 | 行距/行数 |
|---|---|---:|---|
| 头图产品名称 | Semibold | 80px | 100px |
| 正文主标题 | Semibold | 72px | 96px |
| 产品名称下 slogan | Medium | 60px | 80px |
| 头图下方卖点、细节模块小标题 | Semibold | 52px | 单行示例 |
| 卖点信息描述正文 | Regular | 42px | 62px |
| 头图下方卖点描述（Caption1） | Medium | 36px | 50px |
| 细节描述、注释、品牌介绍（Caption2） | Regular | 36px | 未给通用行距 |
| 价格、数字 ICON | Semibold | 100px | 未给通用行距 |

这是通用使用示例，不能覆盖具体模块的局部规则。例如细节子标题局部标 Medium 52/66；FAQ 主标题 60px；参数正文 42/76；品牌正文 36/62，均按对应模块执行。S36 的第一列部分类别标题原图已有重叠字形，以上按清晰可读的使用场景命名，不猜测重叠标题。

## 颜色与安全区的使用原则

不要把一张板中的颜色数值当成全站仅允许的色板。商品摄影、场景与图标强调色可依产品调整；文字、分割线、模块底色中明确指定的颜色按模块执行。

| 色值 | 已明确的用途 |
|---|---|
| `#FFFFFF` | 正文、细节、参数等指定白色页底；合适深底上的反白文字 |
| `#000000` | 浅底主文字、FAQ 条目标题 |
| `#585858` | 多个模块的描述、数字单位与分割线 |
| `#F1F2F1` | 细节文字块与品牌介绍底色 |
| `#D7D7D7` | 参数分隔线 |
| `#656565` | FAQ 描述文字，独立于一般描述灰 |
| `#E9E9E9` | 主打卖点网格默认背景，可按页面统一调整 |
| `#AEAEAE` | 主打卖点网格默认分隔线 |

常见正文文字安全区左右各 80px；多图、分块图片常见左右各 50px。FAQ 明确左右各 100px；主打卖点网格最外侧文字安全区各30px。读对应模块尺寸，不能强行把安全区统一成一档。图片是否满幅、图文结合底图是否受 50px 边距约束，也按局部版式判断。

140/100/80/70/50/40/30/20px 在多处标注中出现，但不构成全站排他性刻度表；参数 76px 行距、FAQ 75px 间隔、图标的局部尺寸等仍合法。
