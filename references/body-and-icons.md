# 正文、图形ICON与数字ICON

## 正文（必备）

来源：S05图文结合规范；S07图文分开规范；S02/S03/S04/S06及S37–S41对应变体。

一个卖点尽量用一张图片展示；一张展示不清楚时必要可用多张。图文结合或图文分开按画面与文案实际需求选择。宽1080px，高不限，建议不超过手机1屏；源图没有给这“一屏”的固定px高度。

### 共通文字与结构

| 项目 | 规范 |
|---|---|
| 主标题 | 72px Semibold，行距96px，1–2行 |
| 正文 | 42px Regular，行距62px，控制在3行内 |
| 对齐 | 标题与正文左对齐 |
| 左右文字安全区 | 各80px，主内容宽920px |
| 顶部 → 标题 | 140px |
| 标题 → 正文 | 40px |

原图称“行间距”；落地时以整行步进/line-height理解96/62/50等值，不在字号之外再额外添加这么多空白。

### 图文分开

文案与图片独立分块，适用于画面不适合摆字、需要突出文案的情况。

- 页底固定`#FFFFFF`，浅底标题`#000000`、正文`#585858`。
- 正文至图片80px；加入图形ICON时，正文至第一排ICON80px，最后一排ICON说明至图片80px。
- 图片左右各50px、图片外底部50px不可侵入，常见图片框宽980px。
- 图片直角，图素与背景色明显区分。文字80px边界与图片50px边界不同。
- 图像高度按商品画面调整；S06/S37/S38/S39/S40/S41的文件高度不是固定模块高度。

### 图文结合

文案叠在图片上。背景不能过于杂乱或干扰阅读；文字区保持简洁、清楚。

- 标题允许`#000000`或`#FFFFFF`，正文允许`#585858`或`#FFFFFF`，按实际图片背景的可读性选择。
- 文字左右80px安全区；底图可以通栏，不能强行套用分开版50px图片框。
- 产品主体与文字之间至少100px留白，不紧贴文字；加入ICON时也给最后一行说明与主体充分留白。
- S05另标“底部背景色固定#FFFFFF”；保留白色底层模板，不把这一注记误解为照片画面只能纯白，从而否定同图明确允许的反白文字。

## 图形ICON（可选）

来源：S12规范板；S02/S03/S37–S40模板。图形应准确概括卖点、线条简洁清晰，整组视觉大小统一。

### 图形和文案

| 项目 | 明确数值 |
|---|---|
| 外圆直径 | 140px |
| 圆框描边 | 3px |
| 内图形线宽 | 统一4px |
| 内图形安全区 | 80×80px，不得超出 |
| 图形颜色 | 黑或深灰色系 |
| 说明文字 | 36px Regular，`#585858`，行距50px |
| 说明长度 | 原文“控制在两行或10个字符内”；采用最多2行、尽量≤10字符的短文案，不能误读成每行10字 |
| 对齐 | 图标与下方文案沿同一竖向中心轴居中 |

80×80px是圆内图形区域，不是ICON外尺寸；140×140px才是圆框尺寸。导视用的青色外方块和绿色内方块不输出到成品。

### 数量、节奏

- 每排最少2个、最多4个；最多两排。上下数量一致、同列轴，单个ICON不放。
- 四列示例中相邻圆框间距100px。2/3个ICON没有另给固定列间距，不自行改数并称其为原图要求；也不强制铺满920px宽。
- 正文 → 第一排ICON：80px。
- 圆框 → 说明：30px。
- 第一排说明 → 第二排ICON：50px。
- 最后一排说明 → 图片：80px。
- 说明由一行增至两行时，文案区相应增高或重排，不能挤占图片前留白。

图形ICON的说明居中，不套用数字ICON的左对齐。S12“上下需为对称数量”已用字形匹配确认，不能解释为两排可各自任意数量。

### 图片内注释

S12/S37标注：36px Regular，行距50px，`#585858`或`#FFFFFF`按图片背景选择。注释距照片内部底边50px；照片外仍留50px底部安全区。这是内注释留白与外框留白两种关系，不能合并成一条。

## 数字ICON（可选）

来源：S35规范板，S41成品参考。示例三组数字不是所有商品固定必须三组。

| 元素/关系 | 明确规范 |
|---|---|
| 数字 | 单行100px Semibold，`#000000`或`#FFFFFF` |
| 单位 | 32px Regular，`#585858` |
| 数字 → 单位 | 10px，单位紧随数字右侧；精确基线偏移未定义 |
| 说明 | 单行36px Regular，`#585858` |
| 说明对齐 | 与本组数字左边缘对齐 |
| 数字 → 说明 | 30px |
| 组间竖线 | 宽2px、高自定义，`#585858` |
| 竖线 → 两侧内容 | 两侧各70px |
| 正文 → 数字组 | 80px |
| 数字说明 → 图片 | 80px |

源图没有明确数字行的行距，不补110px等值为规范。分割线高自定义，不从例图锁死线高。

S35末尾局部标30px；S41成品及S07/S12分开版图片外底距50px。普通图文分开页用50px；精确还原S35局部时保留30px并说明来源差异，见 [evidence-notes.md](evidence-notes.md)。
