# 设计校对清单

只检查当前使用的模块。数值以对应模块详细规范为准；此表用于避免遗漏，不覆盖模块中的例外。

## 全局

- [ ] 设计基准宽1080px；没有把5760px演示板当成商品图。
- [ ] 使用MiSans，字重按模块指定的Regular/Medium/Semibold。
- [ ] 图片上的尺寸箭头、编号、规范标题、半透明导视色块已从成品移除。
- [ ] 对应模块的文字/图片安全区分别正确；没有把FAQ100px、通常文字80px、通常图片50px混用。
- [ ] 指定底色、文字灰与分隔线色正确；没有把产品摄影和可调背景限死为一张全局色板。
- [ ] 未标注的高度/字重/间距已按实施选择处理，不对用户宣称为固定原图要求。

## 头图与主打卖点

- [ ] 产品名称、slogan、logo齐全；名称80/100 Semibold，slogan60/80 Medium，各1–2行。
- [ ] 文字与logo在左右80px安全区内；产品完整、居中，文字背景干净。
- [ ] slogan没有换成圆点卖点列表，卖点放头图下方的独立模块。
- [ ] 版本标签、米家接入标识使用对应正确模板；标识颜色与位置符合专门规则。
- [ ] 标签70px高、4px描边、20px圆角、42px Medium、左右内边距20px；无标签时文案上移。
- [ ] 米家角标190×95px，右下各80px；使用角标时同时在整页最底部放配套蓝色说明。
- [ ] 头图底部可选信息只一行；没有用符号堆叠规格内容。
- [ ] 主打卖点网格位于头图下；若有价格模块，则在价格模块下。
- [ ] 主打单格539×280px不含线、横线2px，网格最外侧文字安全区30px；整组底色统一。
- [ ] 网格大小与标题/描述组合一致；两行标题不配描述；标题+描述各一行。
- [ ] [anti-patterns.md](anti-patterns.md) 中每一项头图与卖点错误已经排除。

## 正文、图标与多图

- [ ] 正文主标题72/96 Semibold，1–2行；正文42/62 Regular，最多3行。
- [ ] 图文结合的主体与文字留白至少100px；图文分开正文至图片80px。
- [ ] 图形ICON圆框140px、3px描边，内部图形4px线宽且处于80×80px安全区。
- [ ] 图形ICON每排2–4个、最多两排，两排数量相等；文案与圆框沿中心轴居中。
- [ ] 数字100px Semibold；单位32px Regular；说明36px，左对齐；分隔线与间距正确。
- [ ] 多图使用实际2/3/4/6图变体；二列480px、三列约313.33px不混用，图片与背景有明确边界。
- [ ] 多图标题背景栏按200px限高处理，不当成字号或每张图的固定高度。

## 细节、参数、品牌、奖项与FAQ

- [ ] 细节图片为直角；图素与底色区分清晰；没有涂抹图素作画面过渡。
- [ ] 细节子标题按局部52/66 Medium执行；描述42/56 Regular；宫格与横版间距不混用。
- [ ] 规格参数只有1P、统一一个主标题；多SKU用横线分组，参数正文42/76。
- [ ] 尺寸图如存在，尺寸线为简洁线性、非彩色；没有尺寸图则文字上移。
- [ ] 品牌紧接参数页下，底色#F1F2F1；一张与两张配图选一种，品牌正文36/62。
- [ ] 获奖标识仅出现在正文，徽标与产品的获奖信息对应。
- [ ] FAQ白底、100px左右安全区、主标题60px、正文42/60且#656565；没有套用72px正文主标题。
- [ ] FAQ圆点半径文字与示例比例差异已按证据说明处理。

## 报告方式

对于实际发现的问题，列出模块、问题、可测当前值、规范值、修正方法和来源编号。来源冲突或无法清晰读取的值单列“待核实”，不捏造实测值。修正时保留用户已有真实商品内容，按来源规则调整排版。
