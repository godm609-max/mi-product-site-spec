# 头图与主打卖点网格

## 常规头图（必选）

来源：S22总览；S25/S29/S30无标签变体；S31/S32有标签变体；错误对照S21/S23。

宽1080px，高度不限，建议不超过手机1屏。产品名称、slogan、logo均必要；版本/型号标签、头图底部说明可选。1554px是示例头图高度，2398px示例含头图和后接网格，不用作全产品固定高度。

### 字体与文案

| 元素 | 字号/字重 | 行距 | 行数/颜色 |
|---|---|---|---|
| 产品名称 | 80px Semibold | 100px | 1–2行；常规黑/白，可按页面色调适当调整 |
| slogan | 60px Medium | 80px | 1–2行；常规黑/白，可按页面色调适当调整 |
| 底部规格/注释 | 36px Medium | 未标注 | 只能1行，常规黑/白 |

文字按模板左对齐。名称过长时调整文案或按词组断成两行，不能改字体、字号、行距或位置凑三行；不能将完整词组拆开。slogan不用卖点展示/列表样式，卖点信息统一放头图下方。

底部可写规格、注释或其他说明，也可留空。头图注释超过1行的内容统一移至品牌介绍模块下方说明，不挤在头图里。

### 位置、留白、logo

| 关系/区域 | 明确值 |
|---|---:|
| 顶部留白 | 140px |
| 文字与logo左右安全区 | 各80px |
| 标签 → 名称 | 30px |
| 名称 → slogan | 50px |
| 底部说明 → 头图底部 | 80px |
| logo示意区 | 200×90px |

logo位于模板右侧，与产品名称对齐、保持在安全区内；不移到左上标签位。根据视觉比例可适当放开10px宽度，不扭曲logo填满示意框。

有标签时，140px顶部后先放70px高标签，再留30px放名称；无标签时文案向上顺移，不保留空标签位。由这些值可推导示例名称区域顶部有标签约240px、无标签140px；这是模板几何，不是字形可见墨迹的独立强制坐标。

商品完整露出，处于画面中心。文字区背景干净简洁，文字清晰，不遮挡产品；名称、slogan与右侧logo不相互侵入。

## 版本/型号标签（可选）

来源：S24；S31/S32正确模板；S21/S23反例。

| 项目 | 规范 |
|---|---|
| 标签高度 | 固定70px |
| 描边 | 4px |
| 圆角半径 | 20px |
| 宽度 | 按字数自定义，文字左右各20px内边距 |
| 文字 | 42px Medium，行距未定义 |
| 位置 | 名称上方，标签与名称左对齐，标签至名称30px |
| 颜色 | 正向规则允许选择线框/文字颜色，两者统一；使用描边样式 |
| 用途 | 版本、型号、容量等；不用作规格参数区 |

无标签时文字上移。标签的标准形式是描边，红底白字实心矩形是错误。S32棕色描边“抑菌版”和S31白色描边“PRO版”均为正确例子。

S24“颜色不限”和S23“不能更改标签颜色”有上下文差异：可以按正向规则选统一的描边/文字色，不能把错误板的实心红底、移位或重制样式推广为新变体。具体保留说明见 [evidence-notes.md](evidence-notes.md)。

## 已接入米家标识（可选，适用于已接入产品）

来源：S24；S25白色纯色版；S31彩黑色版；S23错误对照。

- 使用官方白色纯色版或彩黑色版，按背景选择；不自行改色、改大小或拆改图形文字。
- 头图角标190×95px，固定右下；右侧80px、底部80px。
- 头图的“已接入米家”标识必须与底部蓝色标识说明同时使用。
- 接入标识必须在头图；配套蓝色说明必须在整页最底部。这与头图内可选单行注释是不同内容。
- 蓝色说明未标明字号、行距、蓝色色号或整体尺寸，不能凭演示板嵌入比例补成固定数值；优先复用正式说明资产。

蓝色说明的来源转录：

> 本标识意味着该产品可以通过米家APP或者小爱音箱控制。请注意本标识仅做软件层面验证，小米及米家不对该产品及企业的生产制造、标准执行、质量监管等方面负责。

转录与资产使用以S24官方说明图为准。S23左例错在接入标识移到左下并改色，描边PRO标签是正确邻例；右例错在实心红底PRO标签，右下彩黑接入标识是正确邻例。

## 主打卖点网格（必备）

来源：S01；S26/S27/S28三种正确文字组合；S20错误板。

固定放头图下方；有价格展示模块时放价格模块下方。本批没有价格模块自身的完整规范。

### 几何与颜色

| 项目 | 规范 |
|---|---|
| 单格 | 固定539×280px，不含分割线 |
| 分隔横线 | 2px，默认`#AEAEAE` |
| 标准模板 | 二列三行六格；中央竖线示例也为2px |
| 左右最外侧文字安全区 | 各30px，与头图80px不同 |
| 默认背景 | `#E9E9E9`，可按页面色调自定义，但整组统一，不跳色 |
| 默认字色 | 标题`#000000`，描述`#585858`，允许按页面色调统一调整 |

二列宽度539×2+2=1080；三行高度280×3+2×2=844px；案例头图1554加网格844即2398px。这些是模板推导。原图未另写每种产品必须正好6条；以二列等格为标准结构，调整条数时保持固定格尺寸和整组样式，不将例子数量升级为无依据硬规则。

### 字体与文案组合

| 元素 | 规范 |
|---|---|
| 主卖点标题 | 52px Semibold，行距72px；必备，1–2行 |
| 描述 | 36px Regular；可选，行距未定义；不能单独使用 |
| 一行标题字符 | S01注明“一行9个字符内”；两行样式未另给总字符上限 |
| 描述长度 | 原文“一行或13个字符内”；制作时建议同时满足一行、≤13字符 |
| 标题+描述的格顶 → 标题 | 80px |
| 标题 → 描述 | 40px |
| 横向对齐 | 格内文字居中 |

不更改字体、字号或字间距；原文此处是“字间距”，不能替换成“行间距”。不能为某一条文案单独加高、变矮或改位置。

全网格只用一种模式：

1. S26：每格一行标题+一行描述。
2. S27：每格仅一行标题，无描述；内容块在格内居中。
3. S28：每格两行标题，无描述；所有格均两行。

两行标题不配描述；一行与两行标题不混用；仅描述不允许。只有标题的模板按对应居中版式安排，不机械套用标题+描述版的80px顶距。

S26/S27/S28文件名中的“1行/2行主标题”实际指头图下方的卖点网格标题，不是产品名称行数变体。完整禁止项见 [anti-patterns.md](anti-patterns.md)。
