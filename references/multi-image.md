# 多图展示

来源：S14规范板；S15两图，S16三图含描述，S17三图仅标题，S18四图，S19六图。

## 用途、顶层文字与背景

用于主卖点下的多场景、多细节展示，按需使用。在遵守图间距、文字规范与可读性的前提下，可以增减图片数量，不把给出的五个案例当成唯一允许数量。

示例底色标`#F1F2F1`，允许按实际情况更改。图上安全区/间距彩条不是最终背景或卡片装饰。

| 项目 | 规范 |
|---|---|
| 模块主标题 | 72px Semibold，行距96px，1–2行 |
| 模块正文 | 42px Regular，行距62px，最多3行 |
| 左右文字安全区 | 各80px，主标题/正文左对齐 |
| 顶距 | 140px |
| 主标题 → 模块正文 | 40px |
| 模块正文 → 图组 | 80px |
| 图组 → 模块底部 | S14模板明确标50px |

## 单图卡片文字

- 小卖点标题只一行：42px Medium，黑/白按背景辨识度选择。
- 小图描述：36px Regular，行距50px，`#585858`，最多两行。
- 小标题与描述间距：S14红字明确30px。模板导视带约20px有差异，不默默用像素观察替换文字标注。
- 原文“卖点标题背景栏限高200px”。200px是背景栏限高，不是字号、行高、每幅照片高度。案例照片下方的标题+描述区约200px，源图未进一步拆分栏高；不要额外叠一个200px标题栏再加描述栏。实施时按给定卡片样式控制整体文字区，并说明解释依据。
- 标题和描述居中置于同宽文字栏；同行图像与文字栏保持一致的边界，避免增行造成横向错位。

## 图组几何

左右图片安全区各50px，可用图区宽980px。横向、纵向相邻卖点间距20px；图片高不限。

| 布局 | 结构 | 图宽 |
|---|---|---|
| 两图 | 2列×1排 | 480px，S14明确标注 |
| 三图 | 3列×1排 | 约313.33px，推导值 |
| 四图 | 2列×2排 | 480px |
| 六图 | 3列×2排 | 约313.33px，推导值 |

二列：`50+480+20+480+50=1080`。

三列：有效宽980px减两处20px间隙后等分，即`(980−40)/3≈313.33px`。这不是原图写出的数值；不能对三列继续用480px。渲染为整像素时可合理分配313/314px，使总宽准确，这属于实施选择。

四图、六图是两排版式，不能误解成单排四列、六列。三列窄图按主体重新裁切，不把二列成品整体等比缩小，从而缩小原规定的36/42px文字。

## 模板选择

| 来源 | 图片排列 | 文字变体 |
|---|---|---|
| S15 | 2×1 | 各图一行标题、最多两行描述 |
| S16 | 3×1 | 各图一行标题、最多两行描述 |
| S17 | 3×1 | 仅一行小标题，没有小图描述 |
| S18 | 2×2 | 每张含标题与描述，纵横间隔20px |
| S19 | 3×2 | 每张含标题与描述，纵横间隔20px |

S15–S19源文件高度分别为1342/1242/1152/2162/1962px，只反映示例图高与内容量，不锁定成新的统一高度。照片600px或约504px、仅标题栏约100px也是案例观察值。

多图场景中的母婴、差旅、办公等为产品案例内容，不能作为后续每种产品的必选场景。S14的480px仅是二列尺寸；“可增减数量”仍以保持文字可读与图片间距为条件。
